# PC Web OS 首版实现与验收

2026-10-25，当前实例本机实施；用户视觉验收尚未进行。范围仅 PC Web 与现有只读业务。生产入口仍为 `http://127.0.0.1:4173/`。

## 后续性能优化

用户认可桌面基础后，已完成首轮显示性能优化，并按最新指令将应用窗口及内部内容改为实色；桌面玻璃保留。最终实色窗口复测为 0.208–0.226s，三轮无超过50ms的主线程任务；四种PC尺寸、实色来源抽屉和零新增滤镜检查通过。下述0.27–0.41s来自移除窗口玻璃前的优化阶段。相同连续缩放操作的主线程耗时由 4.83s 降为 0.27–0.41s，三轮中位数 0.281s；长任务由 37 次降为 0–1 次。新增 3 项前端测试，当前为 38/38。完整证据及适用范围见 [PERFORMANCE.md](PERFORMANCE.md)。下文保留首版历史验收记录。

## 证据与边界

截图、几何审计、材质检查、缩放前后记录及测试输出位于 `.impeccable/review/web-os/`，此目录不进入 Core 发布及贡献。主要图为 `desktop-1440.png`、`dual-1440.png`、`cards-edit-1440.png`、`glass-settings-1440.png`；四尺寸分别以 desktop/window/dual 前缀命名。

同步／异步问答、损坏／未知格式、附件、修订、多最终答复、缺失答复及完整摘要筛选由现有单元与 HTTP 测试覆盖；本轮未在浏览器为每一种情况重新创建模拟数据。隐藏页面的轮询条件有模型测试，本机浏览器真实隐藏／唤醒未单独计时。

本轮未验证 Safari／Firefox、真实设备、手机端、大规模档案/FPS性能基准、完整 WCAG 审计或真实用户任务完成率。低透明度与深色染色可由用户自由调整，不保证任意自选组合的文字对比度。自动测试及当前 Agent 走查不代表用户已认可视觉质量。
