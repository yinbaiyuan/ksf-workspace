# KSF PC 工作台 Web OS

本轮将既有只读对话工作台放进可扩展桌面。根地址首先显示桌面；显式聊天与旧版路由链接打开对应应用窗口。以 PC Web 为范围，不开展手机端适配或新增业务写接口。

## 方向与首屏

保留原创雪山、登山者、日出云海与用户材质偏好。32px 状态栏、悬浮 Dock、实色应用窗口及玻璃桌面卡片构成外壳；清晰的长文阅读区保持独立。视觉与窗口操作参考 react-ui-os，应用注册思想借鉴 ProzillaOS，均未引入整套框架或第三方图片。

状态栏区分真实服务健康检查、采集是否启用、最近同步；不以连接成功或最近上报冒充 Agent 实时运行。日期时间使用本地时区。Dock 提供对话工作台、显示桌面、卡片库与玻璃设置；对话窗口列表可聚焦具体实例、新开对照、将最近两窗并排。显示桌面临时隐藏窗口，再次操作恢复。

## 应用窗口

首个业务应用为对话工作台。归属 → 聊天 → 全部轮次 → 请求／路由／结果的既有内容语义不变，保留采集诊断及旧版路由入口。应用定义包含稳定 ID、名称、图标、组件、多实例规则、默认和最小尺寸，通过统一 openApp 启动。

普通窗口默认 1180×740，最小 480×420，按可用桌面限制尺寸与位置。支持标题拖动、边缘缩放、置前、最小化、关闭、最大化还原、左右半屏；最大化保留状态栏和 Dock。窗口菜单提供移动与调整大小的键盘输入入口。

各窗口独立持有阅读定位、搜索、轮次筛选、栏宽、章节与滚动。新开对照复制当前阅读上下文，再独立操作。卡片打开聊天优先复用同聊天窗口；明确“在新窗口打开”创建新实例。窗口宽度 ≥1100px 显示三栏，760–1099px 归属进入抽屉，<760px 两个目录均通过抽屉进入。业务抽屉由统一协调器管理所属窗口和触发控件，关闭后恢复焦点；玻璃面板为独立非模态实色面板。

## 桌面卡片

卡片库与桌面来自 WidgetDefinition 注册表，每种内置卡片最多一张。继续阅读使用最近位置；最近对话使用任务列表；归属概览表示有记录的目标，不将跨归属聊天重复相加；采集状态显示配置与最近同步。

12 列布局仅在编辑模式允许拖动、右下角缩放。移动按钮获得焦点后，方向键移动，Shift＋方向键缩放；完成保存，取消恢复进入编辑前布局。支持移除与从卡片库重新添加。

## 内容与兼容

四类主归属、关联对象、历史切换、精确能力来源和计数语义沿用现有接口。每个窗口内消息按请求、结果与过程分区，每条仅展示一次。原消息 ID、原文、修订和档案顺序不变；DOM ID 增加窗口命名空间。已知完整同步／异步问答结构化展示，未知和损坏格式回退原文；原文查看与复制始终保留完整包装。

target/project/task/turn/section/tab、view=routes/session 链接继续兼容。活动窗口反映到 URL，浏览器历史携带窗口 ID；前进后退恢复对应上下文。根地址不自动重开窗口；继续阅读可恢复有效位置，失效记录显示可重试错误，不猜造替代正文。

## 本机偏好与更新

ksf.workbench.desktop.v1 保存卡片布局及普通窗口尺寸，读取损坏或拒绝访问时回退，保存失败有提示。现有阅读、分栏和 material.v1 保持兼容；Dock、状态栏、桌面卡片材质可调；旧窗框参数保留兼容数据，应用窗口使用实色。

请求按规范化实际 URL 共用缓存和在途请求，沿用 3 秒更新；最小化暂停专属订阅，隐藏页面不发新轮询。错误保留成功数据，更新不改变选中轮次、窗口焦点或滚动。桌面卡片拖动和缩放按合并动画帧同步玻璃采样位置，位置变化不重建位移图；应用窗口不挂载光学组件，关闭时释放业务观察器、监听和订阅。

## 验收边界

覆盖 1024×768、1280×800、1440×900、1920×1080 的桌面、普通窗口与双窗。工程测试、当前 Agent 浏览器走查与真实用户视觉认可分开记录。实际结果见 WEB-OS-REVIEW.md；未做 Safari/Firefox、真实用户测试、手机端或大规模性能基准。


## 当前应用窗口材质

2026-10-25 按用户最新要求，应用窗口改为实色界面，移除窗框及窗口内部的玻璃折射、模糊、背景副本和光学观察器。雪山、桌面卡片、Dock、状态栏及系统抽屉保留桌面材质；设置仅展示生效对象，旧参数保留兼容读取。性能验证见 PERFORMANCE.md。
