# 版本、平台与支持范围

本文按当前开发实现说明能力边界。精确Core版本读取build.json、manifest及release.json，来源和正式发行状态以发行凭据与实际发行记录核对；development标记不能当作正式发行。

## 版本分别管理

| 标识 | 所属范围 |
| --- | --- |
| Core版本 | 程序、系统定义与随包文档 |
| launcher protocol 1 | Core外固定入口与事务恢复 |
| Manifest schema 1、sdkVersion 1 | 当前完整应用清单与运行契约 |
| SDK工具包1.0.0 | 当前开发工具包及公共类型，不等于业务数据版本 |
| 应用version | 不可变执行包；同版本不同内容拒绝 |
| dataStores.schemaVersion | 应用自己的受管JSON格式 |
| ai-task-v1 | 有界AI任务提交与结果契约 |
| codex-conversations-v1 | 原生Desktop会话服务契约 |
| 能力id@version | 可解析的精确定义及依赖 |

当前完整新SDK v1不加载历史旧结构。最低Core、平台及Node ABI要求由清单与宿主核验；运行在一个平台上不能证明所有原生依赖跨平台可用。

## 平台与能力

| 能力 | macOS ARM64 | Windows x64 | 验证边界 |
| --- | --- | --- | --- |
| 固定入口、随包Node与共享CLI | 已接入 | 已接入 | PowerShell原生恢复和ZIP引导分别验证 |
| 主服务、应用宿主与通信 | 已接入 | 已接入 | 真实网络、登录启动和长期运行各自验收 |
| 工作台及通用应用包 | 已接入 | 已接入 | 原生浏览器UI、终端和文件行为不能由模拟代替 |
| 系统文档阅读器 | 当前版本交付时验收 | 程序与原生UI分别记录 | 不以共享源码声称两端UI全部通过 |
| Desktop会话 | 有按版本适配 | 有按版本适配 | 私有IPC必须按精确客户端回归 |
| macOS x64、其他架构及Linux | 没有完整随包验收结论 | 不适用 | 识别代码不代表发行与业务支持 |

Node当前随包24.21.0。Desktop稳定0.163.x及已记录的Windows0.165.0-alpha.1.2适配范围见[平台说明](../runtime/platforms.md)；不据此放宽到全部alpha或其他版本。

## 当前边界

- 没有不可信第三方代码OS沙箱或独立离线发布签名根；同源会话与包摘要各有有限用途。
- 没有自动跨模型切换、通用API未知结果对账或通用跨文件业务事务。
- 没有自动知识采纳或长期知识晋升。
- 没有离线网络代存转发、任意Agent远程唤醒或完整跨共同体委托状态机。
- 配置导出不是完整备份；程序回退不自动恢复业务数据。

## 怎样声明通过

编写完成、构建通过、程序测试、隔离浏览器、本机安装、双机网络、正式发行、用户验收分别报告。测试记录说明日期、源码摘要、平台、输入和未覆盖范围，不能跨版本继承全部健康结论。
