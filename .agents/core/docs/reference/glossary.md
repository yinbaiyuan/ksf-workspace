# 术语与容易混淆的名称

| 名称 | 本文档中的意义 |
| --- | --- |
| KSF Core | 可升级的程序、系统能力、契约、文档及模板源 |
| 工作区模板 | 从Core生成的初始用户目录与随包系统 |
| 用户实例 | 用户自己的正文、设置与本机运行入口，默认一设备一个 |
| 人机共同体 | 以人为主体，人与AI持续协作积累并参与外部合作的整体 |
| 宿主Agent | 实际理解和执行工作的模型运行环境及执行者 |
| ksf-runtime | 固定入口搭档定义，由宿主Agent履责 |
| core/runtime | 随Core分发的程序与引导目录 |
| runtime-data | 本机运行与恢复数据，内容按所属模块分别管理 |
| 主服务 | 独立于浏览器运行的应用与公共服务宿主 |
| 应用后台 | 某一应用的受管Node进程，持有其业务工作流 |
| 窗口／卡片 | 应用提供的人机交互入口，持有独立界面租约 |
| ability | 协同、搭档、基本功和数据包的统称 |
| capabilities | 既有context命令名；不另设一种能力对象 |
| Cooperation | 多责任协作约定，不是程序工作流引擎 |
| 应用工作流 | 应用自己定义的业务步骤、状态、等待、授权与恢复 |
| project | 具体工作的目标、决定、进展与成果入口 |
| repository | 实际工程与Git历史，可以多对多关联项目 |
| knowledge | 可独立理解的认知、依据和适用条件 |
| task／ksf task | 宿主聊天逐轮归档的任务，不等于业务任务或AI任务 |
| aiTaskId | 应用AI服务受理的有界模型任务身份 |
| turnId | 宿主可靠提供的原生聊天轮次，不按工具数猜测 |
| taskId／业务 | 业务载荷中稳定目标标识，与聊天档案taskId按语境区分 |
| operationId | 一次可查询/对账操作的稳定身份，同编号绑定同请求 |
| messageId | 一次逻辑消息身份，网络重试不改变内容或ID |
| requestId | 一次独立业务协作请求和反馈的关联身份 |
| appRunId | 应用自己持有的本地运行，Core不解释内部步骤 |
| etag | 读取时的内容身份，支持相等条件写入 |
| revision | 相应记录的修改序号，不跨对象比较大小 |
| CAS | 比较读取基线再保存，冲突时保留草稿并重新核对 |
| schemaVersion | 对应持久格式或清单版本，依所属契约解释 |
| sdkVersion | 应用与宿主运行协议版本，不等于SDK工具包版本 |
| 应用version | 不可变执行包版本，不等于业务数据schema |
| definition_digest | 实际能力定义摘要，用于核对读到的正文 |
| retain／持久保活 | 保存“该应用仍需运行”的需求，不自动重做外部动作 |
| lease／租约 | 有界生命周期内的客户端、调用或任务持有关系 |
| delivered | 通信持久接收已确认，不表示人已读或业务完成 |
| acknowledged | 应用持久接管已确认，不表示业务执行成功 |
| reconciling／unknown | 原执行结果需核对，不能推定失败并新建操作重发 |

数值必须带所属对象、契约和时间：配置revision不能替代包摘要；消息回执不能替代用户验收；数据备份不能自动证明旧程序能读取。完整流程见[任务](../handbook/task-execution.md)、[AI](../handbook/ai.md)和[通信](../handbook/collaboration.md)。
