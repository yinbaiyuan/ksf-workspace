# KSF手册阅读器

“KSF手册”是随Core提供的只读阅读应用。它读取当前实例的系统手册与明确登记的配套说明，不创建应用后台，也不保存第二份正文。

## 打开和选择路线

先运行ksf open或使用已有工作台，打开应用列表中的“KSF手册”；系统设置入口也提供阅读入口。首次安装沿随附应用机制完成，之后停用或卸载不会因阅读链接被自动撤销。

首页提供理解、使用、开发、机制、维护五条路线。左侧按路线显示目录，中间阅读正文，右侧是本页大纲。窄窗口先折叠大纲，再将目录收进窗口内面板。

## 搜索与跳转

输入中文、英文或命令片段，搜索标题和正文；可按路线筛选。结果显示页面、命中摘要和相应章节。点击大纲、内部链接或上一篇/下一篇可继续阅读，前进后退保留本窗口的历史。

复制章节链接后可在当前实例工作台打开。链接定位使用应用ID、系统文档相对路径和锚点，不含本机绝对路径、令牌或私人正文。跨设备需要相同文档版本和对应服务入口。

外部链接明确标识，由用户点击打开；源码与协议参考可以转入现有文档应用。阅读器没有编辑、保存、解锁、删除和执行命令按钮。复制示例不等于执行授权。

## 图片、代码与图表

本机图片、代码高亮、数学公式和Mermaid使用随包资源，不依赖远程字体或脚本。图表失败时显示错误和原始代码，正文仍能继续阅读。代码复制只复制文本，不运行Shell。

多窗口的当前页、滚动位置和历史各自独立。应用菜单、工具栏和窄窗面板沿用工作台边界，不覆盖其他窗口。

## 更新与异常

目录和离线搜索索引由当前Core文档生成并带摘要。Core更新或重新载入时刷新目录；本地正文已改但索引未重建时，正文仍可读，并明确提示全局搜索可能滞后。维护者重新生成索引后刷新即可。

缺页显示原路径和重试，不自动跳到无关章节；锚点不存在时提示具体章节缺口。图片和图表各自报告失败，不将整页伪装为空白。服务停止时先恢复主服务，离线指不需要互联网，仍需本机服务运行。

## 核验与限制

可以在断开互联网后检查目录、正文、搜索和本地资源；打开两个窗口分别阅读，确认位置不串扰。阅读不会修改文档、用户配置和业务数据。

这是一项可信本机前端应用，工作台的同源环境不构成恶意第三方代码沙箱。打印、笔记、AI问答、编辑和跨设备阅读进度同步不属于本版功能。
