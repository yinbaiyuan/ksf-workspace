# 验证、诊断与交付清单

## 自动检查

遵循[统一测试规范](../testing.md)。首次准备、锁文件变化或环境失效时运行 npm ci；按本次输入变化执行必要的 typecheck、check 和 build。第一方应用使用 `ksf test --component app:<应用ID>`，风险变更显式补齐 `--suite full`。check的error阻断交付；warning是需要人工复核的直连模型、凭据或全局CSS线索，不是沙箱或完整安全扫描。打包器额外检查包容量、静态依赖与资源。原生二进制需验证target和实际运行，不以文件存在证明兼容。

对业务规则编写有意义测试：幂等、并发、结果采用、迁移、重启。不要只测试实现函数被调用或制造与业务无关的测试数量。

## 界面与生命周期

- 主窗口正常/最小尺寸、最大化、标题栏40/68px、窄窗工具栏溢出、侧栏和大纲。
- 多窗口的活动状态、快捷键、搜索、分页、阅读位置、右键菜单、弹层焦点及关闭保护。
- 同类两张卡片与两种类型，配置独立，隐藏暂停刷新，拖动/缩放/分组/键盘行为不被应用拦截。
- 崩溃、样式/模块加载失败、重试、关闭时异步挂载和清理，旧回调不污染新实例。
- 安装、升级pending、最后窗口关闭、后台任务排空、停用、卸载、重装，配置和布局可恢复。
- 记录主服务startedAt，确认应用安装升级期间未变化；宿主升级本身另行说明。

## 文件与AI

文件：保存与外部改动冲突、草稿恢复、移动及图片、权限拒绝、保存准备失败时阻止后续Git操作。写测试使用临时仓库/目录。

AI：无profile、禁用配置、能力不匹配、材料超限、跨应用引用拒绝；同键同请求返回同任务，不同内容冲突；关闭窗口/取消订阅不取消任务；分页事件不丢；结构失败不采用；断线/取消未确认/重启进入核对而非盲重放。

模拟执行器证明流程和接口；真实供应商成功证明特定账户/模型路线。两者分别记录，不默认发付费请求。真实中文输入法、读屏、跨浏览器、Windows、断电和长期运行需专项实测，未测就明确列出。

## 排障顺序

1. 检查应用商店启用状态、版本和pending，核对错误code。
2. 核对宿主SDK/平台和包摘要，检查资源路径，不编辑安装包绕过完整性。
3. 后台应用查看系统AI诊断中的后台错误；AI按编号读取原任务，核对profile及attempt状态。
4. 文件冲突保留草稿与磁盘；数据损坏保留原件与备份，不写空默认值覆盖。
5. 进程结果未知先核对持久记录，不能仅凭历史PID结束进程或通过改任务文件释放额度。

## 交付

安装包与索引/校验值；完整源码、SDK引用、锁文件及许可证；配置和隐私说明；测试/浏览器证据、支持平台、已知限制；版本及数据迁移/回退说明。不得包含真实凭据、私有项目材料或当前实例用户数据。

## CLI 与通信验收

以下针对[应用 CLI](cli.md)和[通信与工作流](communication.md)，是逐项验收要求。实现和程序测试不能自动等同于全部业务、故障和平台验收通过。

| 领域 | 必须验证的行为 |
| --- | --- |
| 应用选择与文档读取 | 未指定应用不预读手册或调用；指定后只读该应用与必要子文档；同任务延续有效选择，同名/换应用不擅自推断 |
| 包内 CLI | 干净环境仅安装应用即可经 KSF CLI 调用，入口/说明/schema/依赖齐全；不另装全局命令；安装、索引及读文档不执行代码 |
| CLI 版本与授权 | 缺入口/越界包拒绝；文档和代码绑定同摘要；校验及取租约无升级竞态；停用/卸载不调用旧入口；来源与命令权限有效 |
| 共享业务状态 | CLI 与工作台复用同一后台；并发版本与幂等生效；长操作查询原 ID；超时不盲重发 |
| 在线消息与材料 | 对端离线直接报告；长文本、多附件、50/200 MiB 及拟议配置上限实测；摘要完整、内存不随整份附件线性增长；配额/中断不产生虚假成功 |
| 回执与本地交付 | 提交后持久保存全部内容及待处理状态才回执；回执丢失可核对；重复/冲突、取消竞态及进程中断不丢已确认消息 |
| 后台与反馈 | 关闭前端仍工作，停止后端不声称独立存活；持久保活与状态发布中断可核对；消息单实例激活；先等后发、反馈先到、多请求和多运行匹配正确 |
| 重投、授权与升级 | 应用接管幂等；原调用未结束不并发重投；持续失败有限重试；停用/暂停不被绕过；升级不双消费，回退保留不可读数据 |
| Agent 端点 | 四种应用/Agent 收发组合及回复地址正确；无业务应用可直接通信；端点越权拒绝；未运行可补查，无适配器不误报唤醒 |
| 实机与兼容 | 全部新 SDK v1 应用回归，旧契约包明确拒绝；macOS/Windows 实机互通和落盘证据分别记录 |

SDK/协议类型、运行时、打包/安装检查与开发模板一致后再报告支持新契约；仅解析文档示例或检查链接不能证明上述行为成立。

## 初始兼容契约与迁移

清单必须声明 `minCoreVersion` 与 `dataStores`（无受管数据填[]）；schemaVersion=1、sdkVersion=1、SDK工具包=1.0.0。安装、启动和回退均核验宿主与数据。受管JSON通过prepareData显式迁移，read不执行迁移；离线检查使用 `ksf app data inspect <appId> --json`。副本不自动恢复，格式不兼容拒绝回退。完整接口及恢复规则见[后端数据](backend-data.md)与[生命周期](lifecycle.md)。
