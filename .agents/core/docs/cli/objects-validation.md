- 真实派生 ksf对象设计师的整个目录，入口、附属规范和 .upstream/ 原始资源均存在；来源 ID/版本标记与基线检查通过。
- 默认与精确读取选择用户派生；归档后回退系统、显式 user 可读取归档、恢复后重新接管；修订只随实际变化递增。
- 已有精确依赖阻止删除，移除引用方后可删除目标；物理删除包含附属文件和基线。
- 两轮结束均核实系统能力文件哈希不变，临时用户对象全部删除，无遗留对象写锁或暂存目录。

上述系统文件不变指验证调用前后比较；本批明确授权的系统定义迁移和路由文档更新另属实现变更。
