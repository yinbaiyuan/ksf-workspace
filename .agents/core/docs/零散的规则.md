ksf 对象定义
    ksf系统的运行能力，由四类对象组成：分别为：
        工作流（Workflow）  第一暴露优先级 可引用 搭档
        搭档（Partner）     第二暴露优先级  配置基本功
        基本功 （Competency） 不在初始发现中暴露  承载专业方法和具体操作，按需使用数据包、脚本、CLI、模板和资料
        数据包（DataPackage）不暴露 不引用

    另外还有一个  项目 对象。  用来管理日常工作。这个更多属于产出，而不是核心运行机制。

    每个能力对象以承载目录管理，目录内定义入口markdown文件：workflow.md、partner.md、competency.md、datapackage.md。具体命名与身份规则见公共元数据规范。

    每个文件都由元数据和正文组成。
        元数据：定义对象的属性，比如名称、描述、标签等。
        正文：定义对象的具体内容，比如工作流的步骤、搭档的成员、基本功的描述等。

    元数据字段、ID、命名空间、版本引用和 YAML 写法统一见 [对象元数据规范](对象元数据规范.md)。





ksf 模型
    ksf 是一个 个人认知和AI能力积累的飞轮系统模型。  核心是把人的认知沉淀到 知识文件夹中。把AI能力沉淀到能力文件夹中。
    知识文件夹的结构以Y模型来组织。 核心是给人看的。
    能力文件夹以 工作流、搭档、基本功、数据包 四类对象来组织。基本功直接承载专业处理和执行方法，程序和资料按需提供支持。
    项目文件夹 用来管理日常工作
