# KSF 用户协作约定

本机制承接原 Codex 全局协作提示中的通用规则和个人偏好。个人正文位于当前 KSF 的 `知识/用户画像.md`；系统定义只持有通用规则与加载方法。

## 唯一正文与生效范围

| 内容 | 维护位置 |
| --- | --- |
| 用户身份、称呼、协作目标、默认气质与表达偏好 | 用户区 `知识/用户画像.md` |
| 短卡加载、持续采用、覆盖关系、交接和通用交付规则 | [ksf-runtime](../../abilities/partners/ksf-runtime/partner.md) |
| 原文核对、范围、时效、当前事实与历史材料的冲突 | [knowledge-route](../../abilities/competencies/knowledge-route/competency.md) |
| 后续已授权修订、基线复核、验证及回退 | [asset-maintenance](../../abilities/competencies/asset-maintenance/competency.md) |

用户短卡是普通 Markdown，不增加对象类型、基本功、数据包或能力索引。文件可不配置；已配置时由入口搭档读取，继续任务复用仍有效的内容。详细个人背景仍按任务需要加载。具体采用和冲突处理以入口搭档为准，本说明不另写第二套运行规则。

这些约定在实际加载 KSF 入口的任务中生效。其他独立工程或会话需要先取得 KSF 入口；文件本身不会修改 Codex 的全局设置，也不改变宿主指令层级。原提示中的“全局宪法”和“项目不能放宽用户级红线”等自定权限表述，由入口搭档现有的用户要求、项目适用范围、长期边界冲突与宿主权限规则承接。
