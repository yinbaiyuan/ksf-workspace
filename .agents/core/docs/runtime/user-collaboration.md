# 根协作设定与短期记忆

当前 KSF 根的 USER.md、BOT.md、MEMORY.md 分别承载用户长期设定、Agent 长期协作方式和短期续接。它们是用户可直接编辑的普通 Markdown，不注册能力对象，不放入对象 user-data，不增加目录、专用 CLI 或额外调度层。具体加载与运行责任由 [ksf-runtime](../../abilities/partners/ksf-runtime/partner.md)持有。

## 职责与采用

| 文件 | 保存什么 | 维护方式 |
| --- | --- | --- |
| USER.md | 身份、称呼、思考习惯与稳定工作偏好 | 用户维护；Agent 只按明确授权修改 |
| BOT.md | 当前宿主 Agent 的协作定位、表达、推进习惯与边界 | 用户维护；Agent 只按明确授权修改，不替代 Core 职责 |
| MEMORY.md | 跨会话续接、未决问题、临时约束、待核实与待沉淀线索 | 当前 Agent 在阶段结束、暂停、切换任务等自然检查点按需维护 |

公司现状、项目进度和具体业务决定回到项目或相关资料；稳定身份与偏好不再特殊归入知识。知识与档案的组织机制继续由各自根说明持有，三文件不替代它们。项目已有检查点时，短期记忆只留入口和必要提醒，不重复完整项目现状。

首次进入当前根，在首次实质回应和处理任务前完整读取三文件；不能以搜索命中、标题或截取片段代替。继续任务复用有效内容；文件更新、用户纠正、任务恢复、上下文丢失或切换根时重新完整读取。切根不沿用前一实例身份或记忆。缺失采用通用默认，不自动创建；不可读报告实际缺口并继续独立工作，不能假装未配置。

仅当 USER.md 确认不存在时，可只读兼容该根的 `知识/用户画像.md`；USER 存在即以新文件为准，即使不可读也不自动合并或用旧画像掩盖故障。旧原文不删除、不自动搬迁。三文件中的引文、推测、待确认内容不是已确认协作要求，短期记忆不产生新的操作授权。

本次明确指令优先。项目约定按其适用范围采用；与用户明确长期边界发生重大冲突时说明具体取舍。所有约定遵循宿主指令、实际能力与权限，不因被读入而扩大权力。责任交接仅传递完成任务所需的约定和线索，不附带无关个人资料。

## 短期记忆维护

自然检查点检查是否有值得续接的内容，不要求每次回复写入，也不把每次成功转成记录。用户要求“只讨论、只读、不保存”时，MEMORY 与项目检查点同样零写入；不能结束后后台补写。缺失不自动创建，初始化需已有明确授权。

条目保持精简，按需要包含：日期、关联事项、来源或材料入口、当前事实、推测或待沉淀性质、未决点及下一步。例如：

```markdown
### 2026-10-23｜示例事项
- 事实与入口：已完成材料核对，详见项目检查点（链接）。
- 待核实：两份来源对适用版本的描述仍有冲突。
- 下一步：取得版本原文后更新同一检查点。
```

写前重读最新基线，同一事项合并，保留并发修改及未解决内容。准备写入期间基线变化时重新读取并比较，只修改可确定的差异；不能用旧全文覆盖新内容。冲突无法安全合并时保留现场并报告。写后重读实际文件，核对未决点、入口及范围，不把尝试写入当作已保存。

已解决且有正式记录的续接项可以清理；待沉淀内容不按时间或容量自动丢弃，不静默截断。条目多时在当前任务中说明整理需要，保留原件和未决内容，不另建隐蔽记忆队列。完整聊天、凭据和不必要的私人材料不写入。

后续“睡眠”机制仍待设计，其处理边界为：核对短期条目 → 确定能力、项目、知识、档案的唯一归属 → 依授权保存并验证 → 回写处理结果。当前不提供睡眠命令、后台整理、定时任务或自动能力晋升。既有明确授权的正常资产保存照常执行，不全部推迟到睡眠。

## 模板、发行与升级

唯一通用模板源位于 Core 的 distribution/template；新工作区生成大写文件名、小写扩展名的 USER.md、BOT.md、MEMORY.md，只含可编辑说明，不包含实际用户或 Agent 的私人身份。真实实例的三文件属于用户内容，不进入 Core 发行或公开贡献。

发行检查根据包内已验证的模板源判断生成文件集合和字节；允许没有三文件模板源的旧包，拒绝未知额外文件、缺失必需模板及篡改内容。升级和回滚仅管理系统范围，不覆盖用户定制、不补写缺失文件；新模板源随 Core 更新，不等于自动重新生成根文件。

## 验证范围

程序测试核对模板生成、字节和名称、私人内容隔离、旧包布局及升级回滚保留。加载、称呼采用、临时覆盖、换根、不可读处理、短期合并和只读零写入由 Agent 使用隔离材料走查；程序测试不冒充 Agent 行为。当前 Agent 走查不能证明独立新会话或长期效果。每轮实际结果由实例开发项目检查点保存，不用下面历史计数替代当前验收。
