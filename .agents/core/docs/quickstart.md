# KSF 快速上手

告诉 Agent 你要做什么即可，例如“记一下：……”“帮我推进：……”“整理这份材料：……”。全新实例会先请你确定称呼和名字，并确认本机名称与登录启动；一次回复就能完成。实例名也是协作伙伴的默认名字，后续可以修改。

## 找到入口

正常孵化完成后工作台会打开一次，Agent 同时提供本机实际可用地址。以后可以让 Agent “打开工作台”，或使用设备上的 KSF 启动入口。工作台左上角 **KSF → 系统设置 → 快速上手** 常驻提供本说明和当前状态；“实例与程序”可改实例名，“个人与协作”可改称呼与协作约定，“内网通信”可改本机显示名，“运行与后台”管理登录启动。

关闭工作台页面后后台继续工作。登录启动只启动后台，不弹出页面；主动停止后台后，可再次打开工作台启动它。关闭登录启动不会停止已经运行的后台。

## 六类内容

| 内容 | 什么时候用 |
|---|---|
| 收件箱 | 先接住想法、文件和待处理材料，后续再归位 |
| 档案 | 保存合同、凭证、正式资料与历史记录 |
| 项目 | 组织目标、进展、任务、资料和协作 |
| repositories | 放实际代码工程，每个工程独立管理版本历史；已有工程也可原位关联 |
| 知识 | 留下认识、经验与可再次查用的内容 |
| 能力 | 复用方法、专业协作方式与执行约定 |

## 数据与 AI

资料和设置保存在你的 KSF 实例目录，实际位置可在快速上手中查看。本机缓存、后台日志和运行状态由程序另行维护。备份需要包含实例资料与设置，并按各应用要求处理后台数据；配置导出只包含部分配置。代码工程与原位关联的外部文件需要分别备份。

当前对话使用你正在运行的 AI 宿主；应用调用 AI 使用“AI 任务服务”中的连接与执行配置。两者分别检查，已有对话能用不表示应用 AI 已准备好。

说“先讨论”就先分析；“执行修改”落实当前明确范围；“记下来”指定要保存什么；“继续上次任务”时说明对应事项。系统遇到无法确认的结果，会先核对实际状态再继续。

打开工作台“系统文档”应用可按五条路线阅读与搜索完整手册；系统设置中也有入口。文件入口为[完整系统文档](README.md)，具体配置见[配置中心](configuration-center.md)、[孵化接口](cli/incubation.md)与[CLI 总览](cli/overview.md)。应用已被停用或卸载时保留你的选择，仍可从文件入口阅读。
