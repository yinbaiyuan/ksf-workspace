临时覆盖不自动回写，默认值不自动落盘。有明确保存或清除授权时，read 取得当前 etag，核对字段及差异，按需要 dry-run，再使用 write/remove，最后 read/check 核验。write 合并顶层键、嵌套值整体替换；`null` 不是删除。冲突先重读比较，不绕过 etag。

清除指定顶层字段使用 `remove --fields`，其余值保留；整份清除须有对应授权。清除后回到定义默认，同一步骤可复用，重新采用或用户更新后重读。{{如字段含义发生变化，说明兼容与重新确认方式；不自动改旧记录。}}
