# 对象核心描述规范

所有对象的核心描述文件都由元数据和正文组成。公共元数据规则统一见[对象元数据规范](../../../../docs/对象元数据规范.md)。

本规范由 ksf对象设计师持有，三项设计基本功在定义核心描述文件时按需引用。它是附属参考资料，不是另一个独立对象。

## 元数据

入口使用 YAML frontmatter，后接 Markdown 正文。字段、ID、命名空间、版本引用及 YAML 写法均遵循[对象元数据规范](../../../../docs/对象元数据规范.md)，本文件不维护第二份字段契约。

既有 7 个系统定义已经迁移为三段 ID、active、0.1.0，并声明精确依赖。新建或派生应通过对象 CLI，保持完整目录、用户修订与来源基线；不以手动编辑公共字段冒充已完成对象服务校验。

## 正文

正文承载对象的具体定义、职责或方法，以及必要的约束和资源引用。不同对象的正文契约后续分别定义，不要求所有对象使用同一套正文模板。

渐进读取时，先取得所需发现元数据；候选适用性检查和执行时再读取对应正文，附属资源按实际需要读取。元数据存在不代表正文已加载或对象已可用。

## 应用范围

基本功的英文名称统一为 `Competency`，复数为 `Competencies`。系统基本功目录使用 `competencies/`，核心描述文件使用 `competency.md`；基本功设计的标识为 `competency-design`。`abilities/` 表示包含工作流、搭档、基本功、数据包四类对象的整个能力区。基本功统一承载专业方法和具体执行操作，脚本、CLI、模板与资料作为支持资源按需使用。

该约定用于 KSF 各类对象的核心描述文件，包括系统与用户对象，以及根 `AGENTS.md` 所定义的特殊入口工作流。

普通参考资料、程序源码和生成文件不因被引用而成为新的对象核心描述文件。
