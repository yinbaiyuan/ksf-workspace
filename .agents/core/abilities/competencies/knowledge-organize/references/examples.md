# 情境例（虚构，非验收证据）

以下说明预期方法，不是模型已通过的测试报告。保存内容由用户形成或指定，归位操作不代替提炼和采纳。

| 请求与材料 | 预期处理 |
| --- | --- |
| “这篇外部反馈理论放哪里合适？” | 建议科学类比，说明是外部来源；只建议，不创建文件或记录。 |
| “把这份课程包记到认知-观察练习。” | 复用或建立采用当前框架的主题，把完整包主存于科学类比，沿包入口引用；不拆出一套重复案例，不生成个人认识。 |
| “把我已经整理好的‘反馈四问’模型保存下来。” | 记录指定模型到提炼模型，保留用户给出的依据和边界；不额外改写或补造证据。 |
| “记录这次练习的观察：隔天才收到反馈时，我已记不清当时的动作。” | 记录观察到定性定量，不自动推广成普遍规律；来源为本次用户自述。 |
| “我想比较即时反馈和隔天反馈，记下假设、验证安排，结果还没有。” | 进入假设驱动，分清计划与尚未执行的结果，不把空结果写成支持假设。 |
| “把‘我目前觉得反馈应发生在下一次练习之前，但尚未验证’记到我的当前认识。” | 原意记录到认知说明的框架，保留限定；其他五步章节保持待形成，不要求先验证或另做采纳审批。 |
| 同一段“反馈应发生在下一次练习之前”，用户要求保存为已经形成的原则，或明确作为个人当前认识 | 前者进入提炼模型，后者进入认知说明；按本次目的判断，不按“反馈”关键词给唯一固定目录。 |
| “先总结访谈，再把总结记到这个主题。” | runtime 核实适用的总结／萃取能力；取得用户要求的结果后按同一授权保存。组织基本功不借归位名义自己扩展为提炼任务。 |
| “把框架里的这一句改成我给出的新表述，其他部分不变。” | 读取最新正文并核对目标，直接替换指定句子，保留其他认识与来源；不额外确认采纳，不顺带润色全篇。 |
| 只要求保存一条与旧认识矛盾的材料，未说明是否改旧认识 | 指出差异并建议补充、并列或替换；待决定的修订保留，不按材料时间自动裁决或覆盖。 |
| 再次记录同一来源包，或写前发现他人新增了批注 | 前者复用且无差异不写；后者停止受影响写入并重读核对，不用旧全文覆盖。 |
| 同级“图谱-材料”以实体与关系组织 | 读取其规则，保持该框架；不套三分区，也不迁移无关单元。 |
| 入口读取失败或规则缺失 | 分开报告读取错误与缺失；对已明确位置可独立处理的内容继续，影响结构的未知选择再澄清，不假装空库。 |

记录完成只反馈实际落点与操作，导航维护必要概述和链接，不把详细正文复制到根入口；知识保存不改变日常业务的资料读取边界。
