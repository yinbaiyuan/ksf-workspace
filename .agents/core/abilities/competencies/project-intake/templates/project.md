# 项目根卡模板

按已确认信息裁剪，通过 project write 的 metadata/body 信封创建；示例不是新增必填元数据规范。不复制不存在的事实，已有根卡优先局部补齐。

```markdown
---
name: 示例项目
description: 用一句话说明项目目标与范围
status: active
---
# 示例项目

## 项目概述

已确认的目标、范围及完成条件；缺失部分保留未知。

## 当前情况

已确认事实、有效决定与来源入口，当前成果及仍待确认的事项。

## 材料分区

| 分区 | 承载内容 | 下一级入口 |
| --- | --- | --- |
| 已有分区 | 概述该目录是什么材料，帮助判断是否进入。 | 链接已有目录概览或主题说明 |

## 工作入口

当前工程或工作区；无工程时按实际情况省略。不要复制工程正文。

## 下一步

具体动作及前提；持续任务只链接其现行检查点，不复制全部计划。
```
