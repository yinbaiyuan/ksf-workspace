# 团队协作示例

独立 SDK v3 应用，示范包内 CLI、共享后台、持久化反馈等待、消息激活和人工审批。它不属于 Core 的内置工作流机制。

运行 `ksf-app check .`、`ksf-app build . --store <测试商店>` 后，通过工作台导入生成的包。在两台设备安装同一应用，双方配对并授权 `team.workflow.v1` 通道和消息激活。用窗口或由用户指定后通过应用 CLI 创建、传递、反馈、审批。

关闭应用窗口后，等待保存在应用数据中；新消息使应用恢复。无需 background:true，也不会持续占用进程。需要持续运行业务的其他应用可使用 context.background 的持久保活接口。

协议和命令见 [CLI 文档](docs/cli.md)。这是流程示例，远程任务不会自动执行 AI 或本机工具。
