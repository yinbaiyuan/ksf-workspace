# 用户说明

保存稳定身份、称呼、思考习惯和工作偏好，由用户自由编辑。Agent 只按明确授权修改，本次明确要求优先；不扩大宿主权限或替代 Core 职责。公司现状、项目进展和具体业务决定在项目及相关资料中维护，不在这里复制。

## 身份与称呼

可填写姓名或希望使用的称呼、时区、默认交流语言；未填写时使用通用默认，不推断身份。

## 思考与工作偏好

可填写希望如何分析问题、呈现依据与取舍、沟通分歧、安排详略及推进工作。只写已采用的稳定偏好，临时要求留在当前任务。

## 协作边界

可填写需要由用户决定的事项及资料使用边界；实际操作始终按当前有效授权与宿主规则执行。额外长期修改需要明确授权；“只讨论、只读、不保存”时同样不写。

Agent 的协作定位与方式见 [BOT.md](BOT.md)。本文件不是能力对象，升级和回滚不覆盖用户定制。
