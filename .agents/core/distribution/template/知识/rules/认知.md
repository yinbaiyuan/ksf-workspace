# 认知类型定义

认知单元围绕一个可讨论、可修订的主题，将理论与模型、事实与案例和当前认识关联起来。此处提供 Y 模型启发的可选组织框架；它只约束认知类型，其他知识类型采用各自框架。公共规则见 [README](README.md)。

这里的五步为“范围、目标、框架、预判、配套”，用于组织本主题的认识。它们与四条路径分别描述内容职责和认知形成方式，不是通用商业推演步骤，也不是执行流水线。采用者按实际材料保留方法来源；Core 不附带课程原件或私人笔记。

实例化模板时替换主题占位，保留目录骨架，并按最终落点重算相对链接。正式主题的认知说明应链接 `../../rules/认知.md`；不要把模板原位置的链接原样复制到新位置。没有实际材料的分区保留为空，不补造正文。

| 位置 | 主要职责 |
| --- | --- |
| 1理论与模型／科学类比 | 学到的外部理论与模型、来源包及适用条件分析；来源观点不自动成为个人认识 |
| 1理论与模型／提炼模型 | 从实践与比较中抽象出的模型、原则、清单及其证据和边界；成熟程度在正文说明 |
| 2事实与案例／定性定量 | 调研、观察、事实、案例、数据和分析，保留时间、场景、口径与来源 |
| 2事实与案例／假设驱动 | 假设、验证设计、实际过程、结果与解释，分别标明尚未执行、得到支持、被限制或结果未知 |
| 3认知／认知说明.md | 以五步组织主题自身的详细认识、采用依据、尚未确定的问题及相关材料入口 |

四条路径说明形成、检验和改进认识的方式：

| 路径 | 作用与证据 | 主要承载位置 |
| --- | --- | --- |
| 科学类比 | 从外部理论与模型理解主题；核对类比条件和不适用情境 | 1理论与模型／科学类比 |
| 定性定量 | 从观察、案例和数据形成或修正判断；保留场景、时间和口径 | 2事实与案例／定性定量 |
| 假设驱动 | 将当前认识转成可检验假设，记录验证设计及实际结果 | 2事实与案例／假设驱动 |
| 提炼建模 | 从实践与比较抽象模型、原则或清单，回查证据与边界 | 1理论与模型／提炼模型 |

四条路径不与五步固定一一对应，不要求按顺序走完，也不因放进“事实与案例”就把待验证假设说成事实。

## 按内容性质和记录目的归位

人形成或指定要记录的内容，系统辅助确定位置；上表定义各位置的职责，不是自动提炼或采纳流程。

- 外部理论、模型与完整课程来源包，通常进入科学类比；人或指定能力已提炼出的模型、原则与清单，通常进入提炼模型。归位操作本身不负责从原文生成新模型。
- 观察、经历、调研、案例与数据进入定性定量，保留场景和已知来源；准备检验的假设、验证设计、过程与结果进入假设驱动。一般未验证的个人想法不因“未验证”就必须移到假设驱动。
- 人对本主题当前的理解、判断和选择进入认知说明，按范围、目标、框架、预判、配套的实际含义选择章节；保存尚不确定的认识时保留其限定，不要求先验证或填满五步。
- 同一句关于反馈的话，记录具体观察、保存已经形成的模型，或表达当前个人认识时，可以分别落在不同分区。依据本次目的判断，不仅凭“反馈”等词选择目录。
- 混合材料整体主存于最合适的位置，其他分区引用其相关内容；只有用户要求拆分或内容本来独立时才分别记录。已有单元与正文优先复用，其他知识类型保持自己的框架。

## 入口与详细认知

`cognition.md` 保存简短定义、三个直接分区的内容概述和五步综述，每步只用一两句说明现状及详细入口。来源包继续沿其自己的综述找到原文，不把包内文件全列到主题入口。

`3认知/认知说明.md` 按以下职责组织，需要时再拆细并更新入口：

- **范围**：研究什么具体问题、适用对象和场景、边界及暂不涉及内容。
- **目标**：希望改善的结果、判断标准、取舍及尚未确认事项。
- **框架**：当前采用哪些关键因素与关系，各自依据及不确定性。
- **预判**：从四条路径展开值得探索的机会，区分机会、已选验证与实际结果。
- **配套**：支持采用与迭代的能力、工具、资源和反馈机制。具体项目排期与过程记录仍留在项目。

只有外部课程资料时，可以先建立导航并说明有何来源。个人目标、经验与当前采用框架尚未形成时写“待形成”，不把外部课程摘要直接写成“我已采用”。知识材料的保存、采用与有效性是不同事实。

## 引用与修订

框架引用理论与事实，验证结果回到框架说明影响，提炼模型保留适用条件。一份正文主存一处，用链接表达关系；已经存在的课程来源包保留整体结构，其他分区引用其相关内容。

新证据与旧认识不同，先说明差异和适用条件，提出补充、并列或替换建议；用户已明确要怎样修订时直接处理，不额外要求采纳审批，不按新文件日期自动覆盖。未解决分歧保留，来源原件不随修订改写或删除。沿用公共记录规则，默认保留原意，内容归纳、提炼和总结由人按需使用能力工具完成；不新增强制修订日志或版本字段。
