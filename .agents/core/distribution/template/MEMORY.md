# 短期记忆

保存跨会话续接所需的短期上下文、未决问题、临时约束、待核实与待沉淀线索。项目已有检查点时只保留入口和必要提醒，不重复维护完整现状，不批量摘录旧聊天或收件箱。

当前 Agent 在阶段结束、暂停或切换任务等自然检查点按需维护，不要求每次回复写入。“只讨论、只读、不保存”时本文件同样不写。更新前重读基线、合并同一事项，保留并发修改和未解决内容；已有正式记录且已解决的续接项可清理。待沉淀内容不按时间或容量自动丢弃，不静默截断。

条目写明日期、关联事项、来源或材料入口、未决点及下一步，区分事实、推测和待沉淀内容。这里的记录不产生新的操作授权，不替代 USER.md、BOT.md 或正式资产。

后续“睡眠”机制待设计：核对短期条目，确定能力、项目、知识、档案的归属，依授权保存并验证，再回写结果。目前没有睡眠命令、后台整理、定时任务或自动能力晋升；已明确授权的正常资产保存照常执行。
